# Procurement Approval Thresholds

| Order Value | Required Approval |
|---|---|
| Under $5,000 | Buyer discretion |
| $5,000 - $25,000 | Category Manager |
| $25,000 - $100,000 | Procurement Director |
| Over $100,000 | VP Supply Chain |

Approval thresholds apply to total PO value across all line items, and
also apply to any amendment that raises a PO's value into a higher
threshold band.
